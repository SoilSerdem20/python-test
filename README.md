# python-test

A simple Python calculator with automated tests, made as a starter example.

## What's inside

| File | What it does |
|------|--------------|
| `calculator.py` | Four basic math functions: `add`, `subtract`, `multiply`, `divide` (divide refuses to divide by zero). |
| `test_calculator.py` | Tests that check each function gives the right answer. |

## How to run

You only need Python 3. No extra packages.

```bash
# See the calculator in action
python calculator.py

# Run the tests
python -m unittest -v
```
